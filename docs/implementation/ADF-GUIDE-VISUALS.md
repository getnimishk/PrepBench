# ADF Study Guide visuals

Every image used by the ADF Study Guide (`backend/app/content/packs/adf/`), where it came from, and why it was chosen.
Images live in `frontend/public/assets/content/packs/adf/` and are referenced from the guide as `/assets/content/packs/adf/<file>`.
They are copied unchanged from the publisher: nothing is redrawn, resized, converted or edited.

## Reuse terms, as published (checked 2026-10-15; not legal advice)

- **The source repository's licence.** The Microsoft Learn Azure Data Factory pages are built from the public `MicrosoftDocs/azure-docs`
  repository, whose `LICENSE` file is Creative Commons Attribution 4.0 International (CC BY 4.0), with code under `LICENSE-CODE`.
  CC BY 4.0 allows copying and redistribution, including commercially, if you credit the source, link the licence and say if you
  changed anything. These images are unchanged. Suggested credit: "Image from Microsoft Learn (learn.microsoft.com), Microsoft, CC BY 4.0, unmodified."
- **The Learn Terms of Use** limit use of site content to personal, non-commercial use and say no image from a Microsoft site may be
  copied unless expressly permitted, but also say that explicit licence terms for a document take precedence. The repository's CC BY
  licence is that explicit permission for the pages whose source is that repository.
- **Not covered by that licence:** third-party logos drawn inside a figure (for example the store logos in `adf-copy-scalability.png`), and
  Microsoft's product icons, which carry their own usage guidelines. These are marks, not Microsoft's authored diagram text, and they
  need a separate decision.
- **Not confirmed:** `data-factory-visual-guide.png` (author terms, above) and `adf-zone-redundancy.svg` comes from the Azure Reliability documentation, whose source repository is not public
  (`reliability-docs-pr`), so no licence file could be read. Treat it as unconfirmed, and replace it or ask before publishing.
- Figures from the Fabric, Azure Monitor and Architecture Center sources were not used, so no other repository's licence applies.

How an image is chosen: it must show exactly what the paragraph claims, agree with the facts verified in the text, be readable at the
chapter width (about 800px), be a concept diagram rather than a marketing graphic or a screenshot, and come from an official source
when two candidates are equal. Raster diagrams are shown at up to the page width and shrink on a phone; the guide's renderer keeps
SVG figures at a readable minimum width and lets them scroll sideways instead.

Date downloaded: 2026-10-15 for every image. The first four were added to the repository in commit f4bfc46 (Chapters 1 to 3); their
origin was re-checked on 2026-10-15 by downloading each source and confirming a byte-identical SHA-256 match.
